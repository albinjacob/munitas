System architecture

The services that make up Munitas, grouped by network trust boundary. Every request into the platform network passes through the API and is checked by the policy engine. Sandboxed agent runs sit on a separate, isolated network with no direct route to the internet or to storage, and still have every tool call checked against the same policy engine.
