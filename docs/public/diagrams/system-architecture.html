System architecture

The services that make up Munitas, grouped by network. Every request into the platform network passes through the API and is checked by the policy engine. Sandboxed agent runs sit on a separate network with no route out, and every tool call they make is still checked by the same policy engine. A step of an organisation's own pipeline runs on a network of its own, with no storage and no key, and reaches the platform only through one small gateway.

  1. Console to API. The Console sends everything a person does to the API as a request.
  2. Console to Sign-in. The Console asks Sign-in who the person is, and Sign-in issues the session that every request carries.
  3. API to Policy engine. The API asks the policy engine whether each request is allowed, and the engine answers with a reason.
  4. Step gateway to API. The step gateway passes a custom step's requests to the API. It forwards only the step routes and answers 404 to everything else.
  5. API to Database. The API records every decision, and the history behind it, in the database.
  6. API to Object storage. The API creates a key in object storage for one task at a time, so a task can open only the files it was allowed.
  7. API to Workflow engine. The API starts a long job, such as a pipeline run, in the workflow engine.
  8. Workflow engine to Worker. The workflow engine hands the job to the worker and keeps it going if the worker stops, so the job can resume.
  9. Workflow engine to Table worker. The workflow engine hands the writing of a large table to the table worker.
  10. Worker to Sandboxed agent run. The worker starts a sandboxed agent run on a network with no route to the internet.
  11. Worker to Derivation runner. The worker starts the derivation runner, which runs one query with no network connection.
  12. Worker to Custom pipeline step. The worker starts a custom pipeline step, which is an organisation's own code, on a network of its own.
  13. Custom pipeline step to Step gateway. The custom step reaches the platform only through the step gateway.
