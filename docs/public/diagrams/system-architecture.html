System architecture

The services that make up Munitas, grouped by network. Every request into the platform network passes through the API and is checked by the policy engine. Sandboxed agent runs sit on a separate network with no route out, and every tool call they make is still checked by the same policy engine. A step of an organisation's own pipeline runs on a network of its own, with no storage and no key, and reaches the platform only through one small gateway.
