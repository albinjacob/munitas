POST /dataset-versions

Create Version

Seal a new dataset version.

A version is sealed on creation, which is why there is no update endpoint: a change is always a new version. The storage prefix encodes organisation, dataset and version and never the class, so a later promotion changes a grant and moves no bytes.

A version that names a records file is also written as an Iceberg table, before the row exists. A small one is written while the request waits. A large one is written by a worker, in a job: the answer is then 202 with the job, the version number and folder are reserved, and the version is sealed, with its table inside it, when the job finishes. table_mode chooses; left out, the size of the records file does.

Only the platform's own workers may call this (the worker token). It names the organisation in its body, so a caller that could reach it without proving what it is could seal a version into any organisation. A person's data arrives through the upload endpoint, which seals under their session.

GET /dataset-versions/{version_id}

Get Version

One version, with the fields a detail screen needs.

version_class deliberately carries only the class question. The name, content hash and record count are joined in here rather than added to the view, because widening the view would make every caller pay for columns most of them ignore, and the view's single purpose is what makes it trustworthy.

The organisation comes from the caller's session (auth.organisation_scope), never from the URL, and a version belonging to another is **not found** rather than forbidden. That distinction is the point: 403 confirms the version exists, which is half of what somebody probing ids was trying to learn. The platform's own workers send the worker token instead and name the organisation they act for. This endpoint also returns object_manifest, the storage keys of the version's files, so it must never answer without one or the other.

A version made from a file somebody brought in also says so (brought_in): the file's name, its size and its SHA-256, who sent it and when. It is null for a version nothing was brought in for, such as one a pipeline made.
